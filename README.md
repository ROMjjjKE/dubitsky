# Сайт ИП Дубицкий Ю. В. — промышленный альпинизм (Гродно)

Статический сайт без сборки и зависимостей: лендинг и страница политики обработки
персональных данных. Открывается двойным кликом по `index.html`, загружается на любой
хостинг как обычные файлы.

## Структура

```
dubitsky/
├── index.html          — лендинг
├── politika.html       — политика обработки персональных данных
├── favicon.svg
├── robots.txt
├── sitemap.xml
└── assets/
    ├── css/style.css   — все стили, токены в :root
    ├── js/main.js      — меню, параллакс, форма, настройки
    └── img/            — hero, gear, insulation, joint, balcony, roof, city
```

## Арт-дирекция

Тема — вертикаль и бетон: панельный фасад, спуск по верёвке, техническая линейка.
Приёмы, которые держат уровень:

- крупная типографика Unbounded, три строки в первом экране;
- волосяные линии вместо карточек, асимметричные блоки услуг;
- один сигнальный цвет (оранжевый), остальное — бетонные серые;
- бегущей строки, свечений, стекла и «парящих» элементов нет намеренно;
- движение: параллакс фотографий на `transform` и появление блоков через
  CSS `animation-timeline: view()`. Без JS анимаций появления — контент виден всегда.

## Что подтвердить у заказчика

Тексты описывают стандартную практику промышленного альпинизма, но часть утверждений
касается конкретного исполнителя, их нужно подтвердить:

- в блоке «Страховка не для вида» — работа на двух верёвках, порядок закрепления,
  правила по погоде;
- в разделе «Технология» — состав этапов и что входит в приёмку;
- в FAQ — ответы про зимние работы, согласование с обслуживающей организацией и сроки;
- в услугах — перечень работ по утеплению, стыкам и балконам;
- часы приёма звонков (сейчас 8:00–20:00).

## Форма заявки

По умолчанию форма проверяет поля и предлагает два действия: звонок и WhatsApp с
подставленным текстом заявки. Для приёма заявок на почту или в CRM укажите endpoint:

```js
const CONFIG = {
  phone: '+375298664464',
  whatsapp: '375298664464',
  formEndpoint: 'https://formspree.io/f/ваш-id'
};
```

Заявка уходит POST в JSON: `name`, `phone`, `work`, `message`, `page`, `date`.

## SEO и доступность

- Schema.org `LocalBusiness` с телефоном, адресом и услугами;
- Open Graph и Twitter Card;
- `robots.txt`, `sitemap.xml`, canonical;
- один `h1`, последовательные `h2`/`h3`;
- адаптив от 320 px, `prefers-reduced-motion`, видимый фокус, skip-link;
- все цвета и шрифты в токенах, контраст текста не ниже 4.5:1.

Верстка прогнана через открытые анти-слоп-чек-листы (Nutlope/hallmark `sloplint`,
heydamir/unslop, miqdadbadjuber/anti-slop): 0 FAIL, 0 REFLEX, 0 WARN.

## Публикация

GitHub Pages, ветка `main`, корень репозитория. Обновление — коммит в `main`.
Для своего домена: Settings → Pages → Custom domain, затем заменить адрес в
`index.html`, `politika.html`, `sitemap.xml` и `robots.txt`.
